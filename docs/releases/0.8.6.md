Ember 0.8.6

- Quake Live’a döndükten sonra Ember oyun yakalamadan yeni bir kare bekler. Kare gelmezse oyun kaynağını yeniden bağlar.
- Windows pencere yakalama gerekiyorsa Ember yeni bir oturum açar. Yakalama yenilenirken aynı replay tamponu devam eder.
- Quake Live görüntüsü alınamadığında Ember yeniden denediğini bildirir.

---

- When Quake Live regains focus, Ember checks for a new game capture frame. If no frame arrives, Ember reconnects the game source.
- If Windows window capture is needed, Ember opens a fresh session while the same replay buffer keeps running.
- Ember shows a warning when Quake Live video is unavailable and capture is being retried.
